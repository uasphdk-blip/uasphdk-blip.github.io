What the application does

This utility prepares encrypted application backups, stores them in the account owner's private Google Drive, and checks that stored copies can be downloaded intact. Its setup supports independent database restore checks and managed backup retention.

It is intended for the owner's own accounts. Scheduled operations are enabled only after their configuration and first cloud execution have been verified.

Google Drive access

The backup client requests the drive.file permission. This permits access to files created by the app or explicitly made available to it. The backup workflow uses a dedicated private folder and ownership marker.

Backup contents are encrypted before they are uploaded. The account owner keeps the recovery passphrase separately.

Optional monitoring

A separately authorized, owner-operated monitor can check the application's public availability and backup receipts, then email incident and recovery notices to the owner's selected address.

Support

Use the user-support email displayed on this application's Google OAuth consent screen. Do not send passwords, authorization codes, OAuth tokens or decrypted backups.
