Purpose and information used

This personal-use utility manages encrypted application backups for its owner. It uses the authorized Google account's email address to confirm that setup is using the intended account. Within the authorized Drive access, it creates a private managed folder, uploads encrypted backup files and non-secret verification receipts, and reads file names, identifiers, timestamps, permissions and downloaded bytes to verify storage and integrity.

Database contents and recovery material can contain sensitive application information. They are encrypted on the owner's machine or configured backup runner before upload to Google Drive.

Authorization and storage

The backup OAuth client requests https://www.googleapis.com/auth/drive.file. Authorization credentials are kept in private local configuration during setup. When cloud scheduling is enabled, required credentials are stored in the configured runner's protected secret storage. They are not included in public source files or these information pages.

Encrypted backups remain in the owner's private Google Drive. The owner controls the backup passphrase and account permissions. The application does not sell Google user data, use it for advertising, or use it to train general-purpose AI models.

Related optional monitoring

If separately authorized, the owner's monitor reads the configured backup receipts and public endpoint responses, and sends incident or recovery email to the owner's chosen address. Alert messages contain operational status, not backup contents, credentials or session proofs. This backup client's Drive permission does not itself grant Gmail inbox access.

Retention and control

The planned automated retention policy keeps seven managed daily copies and four managed weekly copies. Rotation applies only to newly managed backup files after verified setup; it does not authorize deletion of unrelated files or earlier manual backups. Safe restore-verification receipts may be retained separately.

The owner can revoke this application's access in Google Account connections and can delete its stored files in Google Drive. Revoking access stops future authorized operations; it does not automatically delete existing backups. Retention and provider quotas are subject to the actual configured and verified job state.

Public pages and contact

These static information pages have no sign-in form, backup-upload form, application analytics or application cookies. Hosting and Google services operate under their own applicable policies.

For access or data-handling questions, use the support email shown on the application's OAuth consent screen. Do not include private backup contents or authentication credentials.

Use of information received from Google APIs follows the Google API Services User Data Policy, including applicable Limited Use requirements.
